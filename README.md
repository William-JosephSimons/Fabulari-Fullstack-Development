# Fabulari

Fabulari is a role-based community chat application being developed for the
3813ICT Full Stack Development assignment at Griffith University.

The project will be completed in two phases:

- **Phase 1:**  The frontend Angular interface with a small Express backend and JSON file
  persistence.
- **Phase 2:** a complete MEAN application using MongoDB and Socket.IO for
  real-time chat.

The repository will use a straightforward `client` and `server` structure so
that each part of the application remains easy to run, test, and explain.

## Brand assets

The original Fabulari logo files are kept in [`fabulari-logo`](fabulari-logo).
The PNG version will be copied into the Angular application when the client is
created.
